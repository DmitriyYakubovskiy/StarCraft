# StarCraft

**StarCraft** — учебный игровой прототип на Unity, вдохновлённый вселенной и механиками серии StarCraft.

Проект демонстрирует создание трёхмерной стратегии и боевой сцены с управляемыми юнитами, противниками, стрельбой, системой урона, визуальными эффектами и игровой картой.

> Проект является неофициальной фанатской и учебной работой. Он не связан с Blizzard Entertainment и не является самостоятельной игрой серии StarCraft.

## О проекте

Цель проекта — изучение разработки стратегических игр в Unity и реализация основных механик управления боевыми единицами.

В текущей версии представлены:

- трёхмерная игровая карта;
- управляемые боевые юниты;
- противники;
- передвижение по карте;
- выбор и управление объектами;
- стрельба по целям;
- снаряды;
- система здоровья и урона;
- уничтожение объектов;
- эффекты попадания и взрыва;
- звуковые эффекты;
- фоновая музыка;
- пользовательский интерфейс;
- отдельные игровые юниты, вдохновлённые StarCraft.

Проект находится на стадии прототипа и используется для отработки архитектуры и игровых механик.

## Реализованные юниты

### Odin

Тяжёлая боевая машина с высоким запасом здоровья и мощным вооружением.

В прототипе Odin используется для проверки:

- управления крупным юнитом;
- наведения на цель;
- стрельбы;
- работы снарядов;
- нанесения урона;
- эффектов попадания и взрыва.

### Brutalisk

Крупный противник, используемый как тяжёлая наземная цель.

Brutalisk демонстрирует:

- управление поведением противника;
- перемещение по карте;
- взаимодействие с другими юнитами;
- получение урона;
- уничтожение объекта;
- работу анимаций и визуальных эффектов.

Набор юнитов и их характеристики могут изменяться по мере развития проекта.

## Основные механики

### Управление юнитами

Игрок может взаимодействовать с боевыми единицами на карте и отдавать им команды.

Базовый игровой цикл:

```text
Выбор юнита
    │
    ▼
Указание позиции или цели
    │
    ▼
Передвижение
    │
    ▼
Обнаружение противника
    │
    ▼
Атака
    │
    ▼
Нанесение урона
    │
    ▼
Уничтожение цели
```

### Боевая система

Боевая система включает:

- выбор цели;
- поворот юнита или оружия;
- создание снаряда;
- движение снаряда;
- обнаружение столкновения;
- нанесение урона;
- воспроизведение звука;
- создание эффекта попадания;
- уничтожение цели при достижении нулевого здоровья.

### Снаряды

Снаряд содержит собственные параметры:

- скорость;
- урон;
- время существования;
- эффект выстрела;
- эффект попадания;
- звук попадания.

После столкновения с целью снаряд наносит урон и создаёт визуальный эффект.

### Система здоровья

Боевые объекты имеют запас здоровья.

При попадании:

1. объект получает заданное количество урона;
2. текущее здоровье уменьшается;
3. при достижении нуля объект уничтожается;
4. воспроизводится эффект уничтожения.

### Визуальные эффекты

В проекте используются:

- вспышки выстрела;
- эффекты попадания;
- взрывы;
- частицы;
- эффекты уничтожения объектов.

### Звук

Для управления звуком применяется Unity Audio Mixer.

Предусмотрены отдельные группы:

- общая громкость;
- музыка;
- игровые звуки.

Это позволяет независимо управлять громкостью разных категорий аудио.

## Запуск проекта

### 1. Установка Unity Hub

Установите Unity Hub с официального сайта Unity.

### 2. Установка Unity

Через Unity Hub установите:

```text
Unity 6000.0.40f1
```

Рекомендуемые модули:

- Windows Build Support;
- Microsoft Visual Studio Community;
- документация Unity.

### 3. Клонирование репозитория

```bash
git clone https://github.com/DmitriyYakubovskiy/StarCraft.git
cd StarCraft
```

Обратите внимание: репозиторий содержит большое количество игровых ресурсов, поэтому клонирование может занять некоторое время.

### 4. Открытие проекта

1. Откройте Unity Hub.
2. Нажмите **Add project from disk**.
3. Выберите папку клонированного репозитория.
4. Откройте проект в Unity `6000.0.40f1`.
5. Дождитесь импорта ресурсов и компиляции скриптов.

### 5. Запуск сцены

Откройте основную сцену из каталога:

```text
Assets/Scenes
```

Нажмите кнопку **Play** в редакторе Unity.

## Сборка игры

### Windows

1. Откройте Unity.
2. Перейдите в:

```text
File → Build Profiles
```

3. Выберите платформу Windows.
4. Добавьте основную сцену.
5. Нажмите **Build**.
6. Выберите папку для готовой сборки.

## Управление

Точная схема управления зависит от текущей версии сцены.

Предполагаемый базовый вариант:

| Действие | Управление |
|---|---|
| Выбор юнита | Левая кнопка мыши |
| Указание позиции | Правая кнопка мыши |
| Выбор цели | Правая кнопка мыши по противнику |
| Перемещение камеры | Клавиши или перемещение мыши |
| Масштабирование камеры | Колесо мыши |
| Выход из игры | `Esc` |

Перед публикацией README рекомендуется проверить управление в текущей сцене и заменить таблицу на фактические клавиши.

## Настройка характеристик

Параметры юнитов и снарядов могут задаваться непосредственно в Unity Inspector.

Пример параметров снаряда:

```text
Speed: скорость полёта
Damage: наносимый урон
Lifetime: максимальное время существования
Impact Effect: эффект попадания
Muzzle Flash: эффект выстрела
Hit Sound: звук попадания
Volume: громкость
```

Благодаря сериализованным полям значения можно изменять без редактирования исходного кода.

## Добавление нового юнита

Общий порядок:

1. импортировать модель;
2. создать материал;
3. настроить Animator;
4. добавить Collider;
5. добавить компонент здоровья;
6. добавить контроллер передвижения;
7. добавить контроллер атаки;
8. указать снаряд;
9. настроить эффекты;
10. сохранить объект как Prefab.

Пример условной структуры:

```text
NewUnit
├── Model
├── Animator
├── Collider
├── Health
├── MovementController
├── AttackController
├── WeaponPoint
└── Effects
```

## Добавление нового снаряда

1. Создайте новый GameObject.
2. Добавьте модель или простой Mesh.
3. Добавьте Collider.
4. Добавьте Rigidbody.
5. Подключите скрипт снаряда.
6. Укажите скорость и урон.
7. Назначьте эффект выстрела.
8. Назначьте эффект попадания.
9. Добавьте звук.
10. Сохраните объект как Prefab.

## Оптимизация

Для дальнейшего развития проекта рекомендуется:

- использовать Object Pooling для снарядов и эффектов;
- не создавать и не уничтожать частицы при каждом выстреле;
- ограничить частоту поиска целей;
- использовать слои и LayerMask;
- применять NavMesh только к подходящим объектам;
- использовать LOD для крупных моделей;
- объединять статические объекты карты;
- использовать Occlusion Culling;
- профилировать CPU, GPU и память через Unity Profiler.
